# Pune Heat Watch

Design a highly polished, vibrant single-page web dashboard for a hackathon prototype called:

“ThermalPune AI”

AI-Powered Urban Heat Intelligence & Green Planning System

TAGLINE:

“Measure. Predict. Cool.”

IMPORTANT:

This is a FRONTEND-ONLY HACKATHON MOCKUP.

Use realistic mock data and simulated sensor readings.

Do NOT build authentication, backend APIs, database integration, real satellite processing, or real AI inference.

The dashboard should LOOK production-ready and technically credible while clearly functioning as a prototype.

CORE PRODUCT IDEA:

ThermalPune AI helps Pune city planners identify urban heat hotspots, understand WHY an area is hot, predict heat risk, and decide WHICH cooling intervention should be prioritized.

VISUAL DIRECTION:

Create a premium, vibrant climate-tech dashboard.

Avoid the boring “standard admin dashboard” look.

Think:

Google Earth + modern climate-tech startup + Bloomberg-style data density + futuristic civic technology.

Use a light warm background rather than a dark dashboard.

IMPORTANT DESIGN RULES

--------------------------------------------------

1. This must NOT look like a generic Bootstrap admin dashboard.

2. Prioritize visual hierarchy and storytelling.

3. The heat map must be the visual centerpiece.

4. Use large numbers and meaningful charts.

5. Use rounded cards but avoid excessive cards everywhere.

6. Maintain generous whitespace.

7. Use strong orange/red heat visualization against cool blue/green environmental elements.

8. Make AI recommendations visually prominent.

9. Make the What-If Simulator look like a flagship feature.

10. The final result should look impressive in a 3-minute hackathon demo.

11. Desktop-first responsive design.

12. Use realistic Pune locations and mock data.

13. No lorem ipsum.

14. No empty placeholder components.

15. No backend.

16. No login page.

17. No unnecessary settings pages.
